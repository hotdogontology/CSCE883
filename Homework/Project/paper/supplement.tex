\section{Evaluation Conventions}
Mismatch is the positive class. Confusion matrices have actual classes as rows and predictions as columns, ordered mismatch then match: $[[TP,FN],[FP,TN]]$. False acceptance is FN and false rejection is FP. Undefined precision, recall, and F1 use zero. AUROC and average precision use saved continuous scores, preferring logit margins over saturated probabilities. Average precision is not trapezoidal PR area. Scores are uncalibrated; no threshold was fitted on the repeatedly inspected diagnostic.

Conditional metrics exclude abstentions and must be read with scored/total coverage. Original ProofNet argument pairs are assumed positives; swapped examples and the four-theorem, 16-pair diagnostic have constructed labels. Compilation does not validate English correspondence. Herald acceptance counts have no independently established binary truth labels. Single-language controls test shortcuts rather than the paired research question.

\section{Trained Informalization}
The Herald adapter trained on 4,096 original pairs, with 64 validation and 64 test pairs. All 64 generations completed; the original-model judge accepted 49 and rejected 15. These counts are not semantic accuracy. A fresh ProofNet adapter trained on 176 original pairs, with 36 validation pairs. Both use one epoch of rank-16 LoRA on Qwen3-14B and the same original English comparison judge.

ProofNet evaluation attempted 54 related-swap pairs. Eight generation-limit exclusions leave 29/46 correct; mismatch precision/recall/F1 are 0.575/1.000/0.730. All 23 scored mismatches are detected, but 17 of 23 scored matches are rejected. Dataset, size, and evaluation differences prevent a controlled comparison with the Herald acceptance survey.
