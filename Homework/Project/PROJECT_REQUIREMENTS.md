# Final-project requirements

Checked November 12, 2026 against the [course project page](https://sites.google.com/view/csce883/project).

- Final report: **6–8 pages**, workshop-paper format.
- The body also says **at least 5 pages, excluding references**. The page does
  not clearly state whether references count toward the eight-page maximum.
  Aim for 6–8 pages overall until clarified.
- Supplementary material: **separate file**, excluded from the 6–8-page limit.
- Include a declaration of group-member contributions in the supplement.
- Suggested sections and grading weights: Introduction 10%; Related Work 10%;
  Data 10%; Methods 25%; Experiments 40%; Conclusion 5%; also title/authors/abstract.
- Presentation: 10 minutes, 12–15 slides, on the final-exam day.
- Submission: PDF report, public repository link, reproducibility code/data/logs,
  presentation PDF; package materials as a ZIP for the course dropbox.

The local `Project Instructions.docx` contains proposal instructions only
(two pages), with a link to the fuller website. It does not contain the final
report section. These notes summarize that website; they are not new requirements.
